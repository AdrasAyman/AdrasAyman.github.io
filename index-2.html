Fake Store Radar

Sole developer

  • Flags lookalike retail domains the moment their TLS certificate is issued — before the scam storefront is live — through an end-to-end pipeline over live Certificate Transparency logs.
  • Matches every incoming certificate against ~31,000 precomputed typosquat permutations across 10 brands using in-memory O(1) hash lookups plus keyword detection, fast enough to keep pace with the CT stream.
  • Persists flagged domains and scoring history in PostgreSQL through SQLAlchemy models with Alembic migrations, exposed over a FastAPI REST API.
  • Detection logic is deterministically testable via an offline replay mode over recorded CT fixtures — which kept development unblocked through a real upstream relay outage.
  • TypeScript types generated from the OpenAPI schema catch frontend–backend contract breaks at compile time; GitHub Actions lints and builds every push, and the full stack runs in Docker.

BoxSolver

3D bin-packing engine

  • Packs 400 items in under 0.7 seconds at 76% carton utilisation with a deterministic 3D bin-packing engine: corner-point placement, best-fit greedy carton selection, and a downsize pass that prevents near-empty cartons going out.
  • Enforces nine physical and business constraints — weight limits, 6-way rotation, gravity support, box grouping, per-type quotas — behind a single validity check, so a new rule is one predicate rather than a rewrite.
  • Output is byte-identical run to run, which makes regression testing possible at all: a pytest suite covers geometry, the HTTP surface and floating-point boundaries, and runs on every push through GitHub Actions.

Whack A Mole

Tracking, filtering and simulation

  • Keeps player tracking live with as few as 2 of 4 sensor returns, using 2D multilateration — a coarse grid search followed by gradient-descent least squares — over UDP-networked ultrasonic sensors.
  • Cut positional jitter by 45% by tuning a frame-rate-compensated EMA filter with kinematic speed gating, and reduced cross-talk with a time-slot beacon that staggers pings across sensor nodes.
  • Streams positions over WebSockets to a zero-dependency browser game client.
  • Removed the team's dependency on physical hardware by building a full simulation mode, shipped as a single-command Windows executable.

Opening Bridge System

Control logic and operator dashboard

  • An opening road bridge that has to detect an approaching vessel, stop traffic, lift, and reset — with under 5-second sensor-to-actuation response end to end.
  • Wrote the ESP32 control logic in the Arduino IDE across 15+ components: 4 sensors, boom gates and LED signalling, sequenced so the gates are always down before the deck moves.
  • Built a WiFi-connected dashboard in HTML, CSS and JavaScript for real-time remote monitoring, bridge operation and manual override from any browser — no app, no install, works off a phone on the same network.
  • Manual override exists because sensors fail: an operator can take the bridge off automatic control at any point in the sequence.
